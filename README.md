# pixijs-parking-playable

**[▶️ Открыть демо](https://kirik-hamster.github.io/pixijs-parking-playable/)**

Тестовое задание на позицию **JavaScript Разработчик (Playable Ads)**.

Игра‑головоломка: нарисуйте непересекающиеся маршруты для красной и жёлтой машин к их парковочным местам, чтобы они неизбежно столкнулись.

[![PixiJS](https://img.shields.io/badge/PixiJS-8.x-%23ff4088)](https://pixijs.com/)
[![Vite](https://img.shields.io/badge/Vite-latest-%23646cff)](https://vitejs.dev/)

---

## 🚀 Быстрый старт

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/yourname/pixijs-parking-playable.git
cd pixijs-parking-playable

# 2. Установите зависимости
npm install

# 3. Запустите локальный сервер разработки
npm run dev
```

Откройте в браузере адрес, который покажет Vite (обычно `http://localhost:5173`).

Для тестирования на реальном мобильном устройстве в одной Wi‑Fi сети используйте флаг `--host`:

```bash
npm run dev -- --host
```

И перейдите по сетевому адресу, отображаемому в терминале.

---

## 📦 Сборка для production

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`. Именно эту папку нужно загружать в рекламную сеть.

## 🎮 Как играть

1. Нажмите на красную машину и, не отпуская, проведите линию к красному парковочному месту.
2. Повторите то же самое для жёлтой машины.
3. Когда оба пути нарисованы, машины поедут и столкнутся.
4. После аварии появится экран с кнопкой перехода на сайт.

💡 Если бездействовать 20 секунд, финальный экран появится автоматически.
